## Positioning

- Codex environment maintenance companion, not a replacement for all CC Switch clients.
- Reads current live Codex configuration; no dependency on CC Switch's internal database or installation on the server.
- Two workflows: connection/authentication sync for new chats; saved model/provider migration for old chats.
- Documentation: English, Simplified Chinese, Japanese and German. GUI: currently Simplified Chinese only.
- Windows desktop and Linux SSH targets. No claims of a macOS GUI, tray, auto-start, installer or cloud service.

**2.6 preview is local and unpublished.** Fixtures do not prove real account authorization; await the user's SSH tests before release.

Documentation presentation references [CC Switch](https://github.com/farion1231/cc-switch). Initial thread-migration inspiration: [codex-model-sync](https://github.com/WangShuai666/codex-model-sync). No borrowed download counts, rankings, sponsorships or official branding.
